# Return to focus — proposed first version

Status: menu entry and planning page added. Gameplay awaits agreement on this plan and the user's picture.

## Purpose

Make noticing distraction and returning to the meeting feel rewarding. The game should take only a moment of attention.

## Core interaction

- Show the supplied character picture on a simple, quiet path.
- Display a short instruction: “Return to the meeting, then tap for one step.”
- A single large button moves the character one small step forward. Support touch, mouse, and standard keyboard button activation.
- Use a brief, gentle movement with a still alternative for reduced-motion preferences.
- Keep the character still between taps. No sounds, reminders, countdowns, penalties, or streaks.
- Provide a clearly accessible link back to the menu.

## Proposed scope

Progress lasts for the current visit only. No account or saved history. The path continues as needed, so there is no finish line to race toward and no required number of taps. Keep this in plain HTML, CSS, and JavaScript alongside the existing wheel game.

## Picture and visual direction

Use the user's picture for the menu card. Confirm whether it is also the character artwork or a reference for the scene when it arrives. Choose the path and background to suit that picture, keeping movement small and the scene calm.

## Implementation after agreement

1. Replace the planning page with the character, path, instruction, and step button.
2. Add one-step movement per activation and a path that continues without losing progress.
3. Add the supplied artwork and any required credit.
4. Check menu navigation, repeated taps, keyboard operation, small screens, and reduced motion in the browser.

## Review

Try it during a meeting: is a tap quick enough, is the movement rewarding without pulling attention away, and does returning feel positive? Adjust those basics before adding further mechanics.
